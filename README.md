# Employee Management System – SQL

## Description

This project contains 60 practical SQL tasks based on an Employee Management System. It demonstrates core SQL DDL and basic DML operations using MySQL.

The practical starts with database and table creation and progresses through data insertion, retrieval, updating, deletion, and table-level DDL operations.

## Database

`company_db`

## Tables

* `employees`
* `departments`

## Tasks Covered

### Part A – Database & Table Creation

* Create database
* Select database
* Create employees table
* Display table structure
* Display available tables

### Part B – INSERT Operations

* Insert employee records into the employees table

### Part C – Basic SELECT Queries

* Display all records
* Select specific columns
* Filter records using `WHERE`
* Filter by city and department
* Filter by salary
* Use `AND` and `OR` conditions

### Part D – UPDATE Operations

* Update employee salary
* Update employee status
* Update city
* Update department
* Increase salary
* Update multiple employee records

### Part E – DELETE Operations

* Delete employees using employee ID
* Delete employees using employee name
* Delete records based on status
* Delete records based on salary

### Part F – ALTER TABLE / DDL Practice

* Add columns
* Modify column size
* Rename a column
* Drop a column
* Add experience column
* Update employee experience

### Part G – Table-Level DDL Practice

* Create departments table
* Insert department records
* Display department records
* Update department location
* Delete department record
* Rename table
* Display table structure
* Truncate table
* Drop table
* Display remaining tables
